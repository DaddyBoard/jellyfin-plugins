Sonarr Placeholder

Show placeholder episode cards for unaired or missing episodes tracked by Sonarr. Placeholders appear greyed-out in the Jellyfin web UI alongside real episodes, with countdown timers for upcoming releases.

Requirements: This plugin relies on the File Transformation plugin to inject client-side JavaScript. Install File Transformation 3.0+ from the Jellyfin plugin catalog before using this plugin.

Sonarr Connection

Base URL of your Sonarr instance (e.g., http://localhost:8989)
Found in Sonarr under Settings → General → Security

Display Options

Master switch to enable/disable the plugin
Include episodes that have aired but aren't downloaded yet
Include episodes that haven't aired yet
How far into the future to show unaired episodes (1-3650 days)

Performance

How long to cache Sonarr data before refreshing (1-120 minutes)
